## APIs

### Farm Service Agency

The FSA exposes data through interactive tools and dashboards (ARC/PLC signup portal, ERP Dashboard, Livestock Forage Program maps), the USDA Geospatial Data Gateway, downloadable Excel and PDF reports, and shapefiles. There is no published public REST/JSON API; programmatic consumers should use the file-based and geospatial endpoints listed below.

**Human URL:** [https://www.fsa.usda.gov/online-services/fsa-online-data-resources](https://www.fsa.usda.gov/online-services/fsa-online-data-resources)
